# Página de Destino OptimusTech

Este projeto é uma página de destino para uma empresa fictícia chamada OptimusTech.

## Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

- HTML
- CSS

## Como Executar

Para visualizar a página de destino, basta abrir o arquivo `index.html` em seu navegador web.

## Estrutura do Projeto

O projeto possui uma estrutura simples e direta:

- `index.html`: Este é o arquivo HTML principal que contém a estrutura e o conteúdo da página de destino.
- `style.css`: Este arquivo contém todas as regras CSS para estilizar a página de destino.
- `assets/`: Este diretório armazena os ativos estáticos utilizados no projeto, como imagens e logotipos.
  - `logo.svg`: O logotipo da OptimusTech.
  - `team.svg`: Uma imagem utilizada na seção "Vagas Abertas".
